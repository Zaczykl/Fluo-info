# Fluo

System magazynowo-sprzedażowy dla sprzedawców internetowych, rozwijany przez
**Golpin sp. z o.o.**

Integruje się z Allegro REST API w imieniu kont sprzedażowych swoich
użytkowników — każde konto autoryzuje program samodzielnie (OAuth, device
flow). Zakres: pobieranie zamówień, synchronizacja stanów magazynowych ofert,
przesyłki (Wysyłam z Allegro), zwroty, wiadomości oraz dyskusje i reklamacje.

Program jest udostępniany innym sprzedawcom w modelu subskrypcyjnym.
Kod źródłowy pozostaje zamknięty.
